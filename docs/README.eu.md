## Zer da

Concat bideo-editore doakoa eta kode irekikoa da, CapCut-en alternatiba macOS, Windows, Linux eta Androiderako. Jendeak benetan CapCut zertarako irekitzen duen, horixe egiten du: azpititulu automatikoak, testutik ahotsera, atzeko planoa kentzea, gako-fotogramen animazioa, efektuak eta tituluak, pista anitzeko muntaketa, 4K esportazioa. Tranparik gabe: ur-markarik gabe, konturik gabe, harpidetzarik gabe, ezer igo gabe.

Dena lokalean dabil, Rust-en idatzitako motor natibo baten gainean eta GPU bidezko konposatzaile batekin. Instalatu, bota materiala, moztu. Azpitituluetarako, ahotsetarako eta mozketarako AA ereduak behin deskargatzen dira Ezarpenetatik, eta gero konexiorik gabe dabiltza. Zure materiala ez da inoiz zure diskotik ateratzen.

**Honetarako ona:** TikTok, Reels eta Shorts, YouTubeko bideoak, tutorialak eta pantaila-grabaketak, podcast zatiak, memeak.

**Makinentzat ere bai:** JSON-RPC API bat, scriptek eta AA agenteek ere bideoa moztu dezaten.

## Nabarmenenak

- 🚫 **Ur-markarik ez. Konturik ez. Ordainketa-hormarik ez.** Inoiz ez.
- 🔒 **% 100 lokala.** Ez da ezer igotzen. Konexiorik gabe dabil.
- 💬 **Azpititulu automatikoak.** Whisper lokalean. Aukeratu eredu baten tamaina, eta estiloa duten azpitituluak izango dituzu denbora-lerroan.
- 🗣️ **Testutik ahotsera + ahots-klonazioa.** Doako ahots lokalak, edo edozein ahots, grabazio-segundo batzuetatik abiatuta.
- 🧍 **Atzeko planoa kentzea.** Pertsonak, objektuak, edo margotu maskara zuk zeuk.
- 🎞️ **Gako-fotogramak.** Posizioa, eskala, biraketa, opakutasuna, bolumena, efektuen parametroak. Kurba-editorea barnean.
- ✨ **100 efektu, iragazki eta trantsizio.** GPU bidez errendatuak, zuzenean aurrebistan.
- ✂️ **Moztu azkar.** Zatitu, ebaki, ripple, elkartu, fotograma izoztu, abiadura. Denbora-lerro magnetikoa, nahi baduzu.
- 🎚️ **Pista anitz, denbora-lerro anitz.** Muntaketa bat baino gehiago proiektu bakarrean. Nahasketa-moduak, mozketa, iraulketak.
- 📝 **Tituluak.** Letra-tipoak, trazua, itzala, atzeko plaka. Aurrezarpenak hasteko.
- 🎙️ **Ahotsaren garbiketa, etengailu batekin.** Zarata murriztu, ahotsa nabarmendu, bolumena berdindu. Gehi urtxintxa, robota, telefonoa eta abar.
- 📤 **Esportazioa.** H.264, HEVC, AV1. 4K 60 arte, 10 biteko kolorea.
- 🦀 **Rust-en motor natiboa.** GPU bidezko konposatzailea, proxyak, hardware bidezko deskodeketa. 4K-a arin mugitzen da.
- 🤖 **Programagarria.** JSON-RPC API bat, scriptek eta AA agenteek bideoa moztu dezaten. Iturburu-kodetik konpilatuz gero, gRPC eta komando-lerroko tresna bat gehitzen dira.
- 🖥️ **macOS, Windows, Linux, Android.** 25 hizkuntza. Aplikazio bera, proiektu-fitxategi berak.

## Deskarga

Bi bide sartzeko:

1. **[Webguneak](https://concatenate.pages.dev/#download)** zure makinarako konpilazio egokia ematen dizu. Hasi hemen.
2. **[GitHub Releases](https://github.com/jub0t/Concat/releases)** orriak plataforma guztietarako konpilazio guztiak ditu, instalatzaile, pakete eta egiaztapen-baturekin. Zuk aukeratu nahi duzunerako.

Concat **beta** fasean dago: badabil, eta oraindik baditu ertz zakarrak. [Kontatu](https://github.com/jub0t/Concat/issues) bat aurkitzen duzunean.

**Plataformak**

- ✅ **Windows** · x86_64 (ARMerako konpilazioak geldirik daude, ikusi [#326](https://github.com/jub0t/Concat/issues/326)). Instalatzaile bat eta `.msi` bat. SmartScreenek sinatu gabeko konpilazio bat geldiarazten badu: **Informazio gehiago** › **Exekutatu hala ere**
- ✅ **macOS** · Intel eta Apple Silicon. macOSek sinatu gabeko konpilazio bat ireki nahi ez badu: `xattr -dr com.apple.quarantine /Applications/Concat.app`
- ✅ **Linux** · x86_64 eta ARM. `.deb`, `.rpm`, `.AppImage` eta Archerako pakete bat. Baita Flatpak bat ere **[Flatpark](https://flatpark.org/apps/app.concat.editor/)**-en, komunitateko Flatpak urruneko bat, bertsio bakoitzaren x86_64 `.deb`-a biltzen duena eta harekin batera eguneratzen dena
- ✅ **Android** · telefonoak eta tabletak
- ✅ **iOS / iPadOS** · iPhone eta iPad, sideload bidez

✅ Bateragarria · 🚧 Garapenean · 🧪 Probatzeko

**Sistema-eskakizunak** eta aukerako ereduen tamainak [webgunean](https://concatenate.pages.dev/guides/system-requirements) daude.
